A tiny program that writes one sentence pitching a bizarre startup idea that sounds absurd until you realise it would actually sell. The pitch it serves:

> We train pigeons to carry encrypted USB sticks between air-gapped offices, so law firms pay per flight for the only delivery no hacker can intercept.

The joke is the business: a pigeon is the only delivery no hacker can intercept, so the absurdity itself is what law firms pay for.

## Run it

```sh
python3 main.py
```

That writes the pitch to `/output/entry.txt` (149 characters, no trailing newline).
